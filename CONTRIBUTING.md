# Contributing

Thanks for your interest in improving TranslationApp.

## Development setup

1. Fork or clone the repository.
2. Open the project in Android Studio.
3. Use JDK 17 and Android SDK 34.
4. Sync Gradle and run the `app` configuration.

## Pull requests

- Keep changes focused and easy to review.
- Use clear commit messages.
- Verify the project builds before opening a pull request.
- Update documentation when behavior changes.
- Do not describe placeholder behavior as real machine translation.

## Bug reports

Please include:

- Android version and device/emulator
- Steps to reproduce
- Expected behavior
- Actual behavior
- Relevant logs or screenshots when available
